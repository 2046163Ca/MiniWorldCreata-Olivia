🌍 Mini World: CREATA (国际服) — Game Introduction<br/><br/>(Also published under the earlier title Mini World: Block Art)<br/><br/><br/>------<br/><br/>📌 What Is It?<br/><br/>Mini World: CREATA is a free-to-play 3D sandbox game developed by Miniwan Technology (深圳市迷你玩科技有限公司). 
It's the global/international edition of 《迷你世界》, built for players worldwide — complete with multi-language support, cross-platform multiplayer, and a massive player-created content ecosystem.<br/><br/>A world made of blocks, with no levels, no class systems, no paywall-locked core features — just pure exploration, destruction, and creation.<br/><br/><br/>------<br/><br/>🎮 Core Game Modes<br/><br/>Mode	What You Do<br/>🏗️ Creative Mode	Infinite resources from the start. Build floating castles, automated farms, music machines, entire cities — anything your imagination draws<br/>⚔️ Survival Mode	Gather resources, craft tools, build shelter before nightfall, fend off hostile mobs, and descend into dungeons to challenge bosses like the Dark Dragon<br/><span class="emoji emoji1f3af"></span> Mini-Games (Gallery / 迷你工坊)	Jump into thousands of player-made maps — parkour, puzzles, FPS arenas, strategy maps, mazes — all one-click join<br/><br/><br/>------<br/><br/><span class="emoji emoji2747"></span> Key Features<br/><br/>• 🌐 Truly Global<br/><br/>Supports 14+ languages (English, Spanish, Portuguese, French, German, Russian, Japanese, Korean, Thai, Vietnamese, Turkish, Italian, Indonesian, Chinese…) — play and chat with people from everywhere.<br/><br/>• 👥 Cross-Platform Multiplayer<br/><br/>Join friends anytime via PC ↔️ Mobile (iOS/Android).
